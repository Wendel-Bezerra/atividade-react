# TechStore — Atividade React

6 componentes (Abas, Toast, Menu Suspenso, Paginação, Barra de Progresso, Acordeão),
responsiva, com Context API (toasts e carrinho globais) e React Router (5 páginas).

## Rodar (GitHub Codespaces)
Crie um Codespace no repositório (o `npm install` roda sozinho) e execute `npm run dev`.

| Página | Componentes |
|---|---|
| `/` Início | Abas, Toast |
| `/produtos` | Menu Suspenso, Paginação |
| `/upload` | Barra de Progresso |
| `/faq` | Acordeão |
| `/carrinho` | Itens do carrinho (Context API) |
